Personal Portfolio Website

A responsive, self-developed website showcasing my technical skills, projects, and development process.

Project Overview

I designed and developed this personal portfolio website to showcase my technical skills, software projects, and development process.

Built using HTML5 and CSS3, the website features responsive layouts, organized project categories, and navigation designed for desktop and mobile users.

Problem & Purpose

I wanted a central place where recruiters and hiring managers could explore my work beyond a traditional resume.

Rather than using a website builder, I chose to develop the site myself to demonstrate my understanding of web development, responsive design, and version control.

Planning & Design

My design process focused on creating a clean, responsive portfolio that makes my work easy to explore.

Wireframes

I planned the structure of the website around clear navigation, organized content sections, and a mobile-friendly layout.

Mockups

The visual design uses a consistent color palette, simple typography, and reusable content cards.

Design Decisions

I selected navy as the primary color, cadetblue for accents, and azure for lighter backgrounds.

I used Flexbox, CSS Grid, and responsive styling to create layouts that adapt to different screen sizes.

I also organized the website into distinct sections so visitors can quickly find information about my experience, skills, and upcoming projects.

Project Architecture

The portfolio is a static website built using HTML5 and CSS3. GitHub manages the source code, while GitHub Pages hosts the published website.

The project uses separate HTML pages and shared stylesheets to maintain a consistent design.

User Flow

Visitors begin on the homepage, where they can explore my background, areas of expertise, upcoming projects, widgets, skills, and contact information.

Project links will allow visitors to open individual case studies, explore source code, and access live demonstrations when available.

Challenges & Solutions

Building my portfolio involved solving layout and usability challenges while developing and testing the website across different screen sizes.

Mobile Navigation

The Challenge

My navigation menu contained several links that extended beyond the screen width on mobile devices.

The Solution

I adjusted the Flexbox layout and responsive CSS to keep navigation accessible and prevent horizontal overflow.

Responsive Layout

The Challenge

I needed the website's cards and content sections to display consistently across desktop and mobile screen sizes.

The Solution

I used flexible layouts, responsive sizing, and CSS media queries to adapt the design to different devices.
